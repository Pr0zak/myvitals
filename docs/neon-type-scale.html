Neon Type Scale

The neon shell has almost no weight hierarchy left. 34 of 46 web font-weight declarations sit at 700 or above, and 32 of 45 Compose weights at Bold or above. When the heading, the label, the value and the list row are all bold, weight has stopped carrying information — nothing recedes, so nothing stands out. Below is the same screen, same content, same colours and sizes. Only the weights differ.

The five roles

RoleSpecUsed forSample
display 32 / 800 / −0.5px The screen title. Once per screen — that is what makes it read as the top of the page. Today
title 16 / 650 Card headings and list-row names. The thing you scan for. Resting HR
body 15 / 450 Supporting lines, dates, sub-captions. Currently 600, which is why nothing recedes. Today · 28-day mean 54
label 11 / 600 / 0.12em / upper Ring captions and micro-labels. Tracking and case already carry it; weight does not need to. MOVE
numeric-lg 19 / 700 / tabular Ring percentages and hero figures — the reading itself. 75%
numeric-sm 14 / 600 / tabular Inline row values. Tabular figures so columns of digits line up. 8,260

Six entries for five roles: numeric needs two sizes because a ring percentage and a row value are the same role at different scales, and splitting them is cheaper than every call site picking a size by hand. They live as one NeonType object beside the existing NeonMV colour tokens, mirrored as CSS custom properties on the web side.

Why it is one change, not seven

Half of this is worse than none of it. A screen where the ring percentages have come down to 700 but the row names are still 700 has lost the old hierarchy without gaining the new one — every element sits at the same weight for a different reason, and the result reads as an unfinished edit rather than a design. That is why the item is sized large and why it was held back rather than slipped in with the rest of v0.39.0.

The scope is 46 web declarations and 45 Compose ones, across Rings.vue, Train.vue, You.vue, Body.vue, NeonNav.vue and their five Compose twins. Mechanical once the scale is agreed, but it has to land in one pass on both surfaces — the parity rule applies, and a screen restyled on web and not on the phone is the same half-done state at a different granularity.

Weights re-measured on the neon surfaces at v0.39.1 — web: 2 at 400, 2 at 500, 8 at 600, 28 at 700, 6 at 800. Compose: 3 Normal, 5 Medium, 5 SemiBold, 28 Bold, 4 ExtraBold. Both panels above use the app's own tokens, faces and geometry from Rings.vue; the numbers shown are illustrative, the type is not.
